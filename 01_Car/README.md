# **Used Car Analytics & Price Prediction Dashboard**


🔗 Live Dashboard: https://usedcar-market-analysis-jnnom72cyjjmvfyejk37mf.streamlit.app/

### Project Overview

The Used Car Analytics & Price Prediction Dashboard is an interactive data science application designed to explore the factors that influence used car prices and provide data-driven vehicle value estimates. Using a dataset of historical vehicle listings, the project examines how key characteristics such as mileage, vehicle age, engine size, fuel efficiency (MPG), transmission type, fuel type, and manufacturer impact market prices.

The dashboard combines exploratory data analysis, statistical visualizations, and machine learning models to help users better understand pricing trends within the used vehicle market. Interactive charts allow users to explore relationships between vehicle attributes and price, identify depreciation patterns, compare manufacturers, and analyze market behavior through a user-friendly interface.

To estimate vehicle prices, the project evaluates multiple machine learning algorithms, including Linear Regression, Random Forest, and XGBoost. Model performance is assessed using metrics such as R-squared, RMSE, MAE, and MAPE to compare predictive accuracy and reliability.

The application also includes an interactive price prediction tool that allows users to input vehicle characteristics and receive an estimated market value based on the trained models. By combining analytics, visualization, and predictive modeling, the project demonstrates how data can be transformed into practical insights that support informed decision-making for consumers, dealerships, and automotive enthusiasts.

### Key Features
Interactive exploratory data analysis (EDA)
Statistical summaries and market insights
Vehicle depreciation and pricing trend analysis
Linear Regression, Random Forest, and XGBoost model comparison
Model performance evaluation and diagnostics
Real-time vehicle price prediction tool
Interactive Streamlit web application
